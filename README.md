# 🐉 D&D 5e All-In-One Ecosystem

> **Единая экосистема для настольных ролевых игр D&D 5-й редакции**, объединяющая аутентичный интерактивный лист персонажа, нарративного ИИ-Мастера Подземелий и тактический виртуальный стол (VTT) с боевым движком.

---

## 🧭 Состав экосистемы

Репозиторий объединяет три ключевых компонента в структурированный монорепозиторий:

```
dnd5e-all-in-one/
├── character-sheet/          # 📜 1. Интерактивный пергаментный лист персонажа D&D 5e
├── ai-master-and-battle/     # 🧠 2. ИИ-Мастер Подземелий & ⚔️ 3. Тактический боевой VTT движок
├── run-character-sheet.bat   # 🚀 Скрипт быстрого запуска листа персонажа (Windows)
├── run-ai-master-battle.bat  # 🚀 Скрипт быстрого запуска ИИ-Мастера и арены (Windows)
└── README.md
```

---

## 📜 1. Лист персонажа (`character-sheet/`)

Полнофункциональный интерактивный лист персонажа D&D 5e в аутентичном средневековом стиле старинного пергамента.

### Возможности:
- **🎨 Parchment Medieval Theme:** Тёплые текстуры пергамента, чернильно-коричневая типографика, золотые акценты, векторные стилизованные иконки.
- **🧙 Мастер создания персонажа (Character Wizard):**
  - Поддержка систем генерации характеристик: Point-Buy (27 очков), Standard Array, бросок 4d6 drop lowest.
  - База рас, классов, архетипов, предысторий и черт.
  - Автоматический расчёт бонуса мастерства, модификаторов, спасбросков и пассивного восприятия.
- **📖 Книга заклинаний & Инвентарь:**
  - Полный компендиум заклинаний D&D 5e с фильтрацией по классам, школам и уровням.
  - Трекинг ячеек заклинаний (использовано / всего).
  - Расчёт переносимого веса и снаряжения.
- **⭐ Модальное окно Level Up:**
  - Пошаговое повышение уровня: прирост хитов, выбор новых заклинаний, распределение ASI (характеристики) или выбор черты.
- **⚡ Zero Latency Compendium:** Локальная база данных правил без внешних сетевых задержек.

## 🧠 2. ИИ-Мастер Подземелий (`ai-master-and-battle/`)

Интеллектуальный ведущий игры на базе передовых LLM-моделей (Google Gemini, DeepSeek, Claude, GPT).

### Возможности:
- **📖 Генерация сюжетных арок (Story Arc Engine):**
  - Создание актов, глав, квестов, таинственных завязок и кульминаций.
  - Учёт предысторий и мотиваций персонажей игроков.
- **💬 Потоковый чат (Streaming DM):**
  - Непрерывный стриминг ответов мастера с атмосферным описанием локаций и диалогов NPC.
- **🎲 Интеллектуальный вызов инструментов (Tool Calling):**
  - Автоматическое распознавание необходимости проверок навыков (Athletics, Stealth, Perception и др.).
  - Броски кубиков d20 с модификаторами персонажа.
  - Бесшовный запуск тактических сражений при возникновении конфликта в сюжете.
- **👥 Кооперативные комнаты (Multiplayer Rooms):**
  - Совместные партии для нескольких игроков с лобби и обменом ходами.

## ⚔️ 3. Тактический боевой VTT движок (`ai-master-and-battle/`)

Полноценный виртуальный стол (Virtual Tabletop) для пошаговых тактических сражений по правилам D&D 5e.

### Возможности:
- **🗺️ Тактическая сетка (Tactical Grid):**
  - Поддержка перемещения по клеткам, линий видимости (Fog of War), укрытий и труднопроходимой местности.
  - Радиусы ближнего и дальнего боя, шаблоны заклинаний (сферы, конусы, линии).
  - 24 готовых тактических пресета карт (подземелья, таверны, арены, леса, лавовые пещеры, корабли, руины).
- **🐉 Встроенный Бестиарий (2 875 существ):**
  - Официальные монстры D&D 5e (SRD + Monster Manual + дополнительные книги).
  - Аутентичные характеристики: КД, кости хитов, скорости, спасброски, иммунитеты, способности и официальные атаки (копья, луки, укусы, дыхания драконов).
  - **Автоматический резолвер бестиария:** когда ИИ-Мастер объявляет нападение стражников или гоблинов, движок автоматически сопоставляет существ с компендиумом и загружает их аутентичный статблок.
- **⚖️ Баланс энкаунтеров по DMG p. 82:**
  - Точный математический расчёт бюджетов опыта (Easy, Medium, Hard, Deadly) и множителей за количество монстров.
- **🤖 Автономный ИИ для монстров (Enemy Bot AI):**
  - Враги самостоятельно оценивают дистанцию, выбирают приоритетные цели, атакуют, применяют заклинания и реагируют на провоцированные атаки (Opportunity Attacks).
  - Проверки боевого духа (Morale System).

## 🛠️ Стек технологий

- **Фреймворк:** [Next.js](https://nextjs.org/) (App Router, Server Actions, API Routes)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
- **База данных:** [Prisma ORM](https://www.prisma.io/) + PostgreSQL (Supabase) / SQLite
- **Авторизация:** Supabase Auth
- **ИИ / LLM:** Vercel AI SDK, Google Generative AI SDK, OpenAI-совместимый API
- **Тестирование:** [Vitest](https://vitest.dev/) (36+ тестовых наборов, 195+ тестов боевого движка), Playwright

## 🚀 Быстрый старт (Локальный запуск)

### Требования:
- [Node.js](https://nodejs.org/) версии 18+ или 20+
- `npm` или `pnpm`

### 1. Запуск Листа Персонажа

```bash
cd character-sheet
npm install
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### 2. Запуск ИИ-Мастера и Боевого Движка

```bash
cd ai-master-and-battle

# 1. Установите зависимости
npm install

# 2. Настройте переменные окружения
cp .env.example .env
# Заполните в .env ваши ключи AI API (Polza.ai / OpenAI / Google) и Supabase

# 3. Примените миграции базы данных
npx prisma generate
npx prisma db push

# 4. Запустите dev-сервер
npm run dev
```
Приложение откроется по адресу `http://localhost:3000` (или `http://localhost:3001`, если порт 3000 занят).

## 🌐 Развёртывание в облаке (Vercel)

Проекты оптимизированы для развёртывания на платформе [Vercel](https://vercel.com/):

- **Лист персонажа:** Укажите Root Directory: `character-sheet`
- **ИИ-Мастер и VTT:** Укажите Root Directory: `ai-master-and-battle`

Оба проекта работают независимо и могут быть развёрнуты на отдельных доменах или поддоменах.
